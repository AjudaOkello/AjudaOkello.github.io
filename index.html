Projects

Book Library Management System

C Programming Data Structures Program Logic & Functions CLI / Menu-Driven Design

Task

Build a console based Book Library Management System in C that lets a librarian manage a book catalogue and its users through a menu driven interface, including adding, viewing, deleting, borrowing, and returning books.

My Role

I designed and coded the system independently, from planning the data structures for books and users through to writing and testing every function in the menu.

Problem-Solving

The main challenge was structuring the program so that book records, user records, and borrowing status stayed consistent as the menu looped and functions called each other. I addressed this by using C structures to group related data, and by breaking the program into small, single-purpose functions for each menu action, which made the logic easier to trace and debug.

Outcome

The result is a working, menu-driven library system that reliably adds, borrows, returns, and deletes books and users without corrupting the underlying records. Building it strengthened my understanding of programming logic, functions, structures, and menu based application design in C.

PWM DC Motor Speed Control

Circuit Design PWM / Motor Drive Circuits Analogue Electronics Circuit Simulation PCB Layout

Task

Design and implement a PWM DC Motor Speed Control system able to vary motor speed from 0% to 100% duty cycle, including power conversion from a transformer, rectifier, and filter stage.

My Role

I designed the triangle wave generator, comparator circuit, isolation circuit, and drive circuit, and simulated and laid out the supporting PCB.

Problem-Solving

The main challenge was getting the comparator to translate a variable reference voltage into a clean, linear duty cycle across the full 0-100% range, while keeping the low-power control side isolated from the higher-power motor drive side. I worked through this using circuit simulation to tune the triangle wave generator and comparator thresholds before committing to the PCB layout, and used an isolation stage to protect the control circuitry from motor-side noise and voltage spikes.

Outcome

The system produced a stable, linearly adjustable PWM output across the full duty cycle range. Working through it improved my understanding of PWM control, motor drive circuits, circuit simulation, and practical electronics design.
